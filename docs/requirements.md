# Requirements Document: MSR Knowledge Base

**Customer:** MSR Research Group Lead
**Role:** Software Engineer
**Source:** Customer meeting notes

## Problem

PhD students are often overwhelmed when they start their research due to a lack of knowledge on data sources, data collection methods, analysis techniques and where to publish.
The customer would like a very straightforward reference tool to be included on a website. With 4 tabs:
**Data Sources, Collection Methods, Analysis Methods, and Publication Venues.**

## User Stories

1. As a PhD student, I want tabs at the top of the page, so that I can switch between the four sections.
   - Done when: Clicking on each of the tabs will show that section and hide the others.
   - Milestone: Page Structure and Navigation

2. As a PhD student, I want to see the available data sources, so that I can choose which data to collect.
   - Done when: Each source presents information about the source including name, data provided and a brief description.
   - Milestone: Data Sources Content

3. As a PhD student, I want to see the data collection methods with their pros and cons, so that I know how to collect data.
   - Done when: Each method presents information about the method including name, purpose and advantages/disadvantages.
   - Milestone: Collection Methods Content

4. As a researcher, I want to see the analysis methods and their use cases, so that I can pick the right method.
   - Done when: Each method presents information about the method including name, type of analysis and typical use cases.
   - Milestone: Analysis Methods Content

5. As a researcher, I want to compare publication venues, so that I can pick the most appropriate one.
   - Done when: Each venue presents information about the venue including name, conference or journal, topic and relevance to MSR.
   - Milestone: Publication Venues Content

6. As a researcher, I want a clean and simple page, so that I can focus on the content.
   - Done when: The information is presented in a very simple table/list format.
   - Milestone: Designing Improvement
